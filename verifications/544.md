# Verification for PR 544: install.sh from releases, and releases are back

Ran on 2026-11-12 on a Mac (Node 22+, npm), from this branch, with a temp `NPM_CONFIG_PREFIX` so nothing touched the real global install. The sandbox repo was not used: the issue has no live steps and nothing here touches GitHub behaviour.

**Bottom line:** I did the release steps by hand, the way `release-cli.yml` (from #545) does them: built, packed `loopway-cli.tgz`, and ran `install.sh` against that directory. It installed, and `loopway --version` printed `2.0.0`. Not checked: the workflow itself running on GitHub Actions (it can only run after merge, on main), the deployed `https://loopway.craftmill.dev/install.sh`, and `curl | sh`.

Re-ran the steps below after the merge. This replaces my first version of the PR (clone and build from `main`), which Matthew turned down in favour of releases like v0.
