### A bug the live run found, and fixed

The first live runs echoed the token as plain text while it was being typed, and ignored Enter and arrow keys at times (the arrow showed as `^[[B`). Every question had been its own Ink app, and starting the next one raced the last one's cleanup, which left the terminal out of raw mode. The fix is one Ink app for the whole walk with a single input handler (`packages/cli/src/setup-io.tsx`). I reran the flow above on the fixed code: no echo (a grep of the transcript for the token found nothing) and every key was taken.
