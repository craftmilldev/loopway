# Verification for PR 525: Home page refresh, the billboard is the site with five scrolling frames

Ran on 2026-11-12, on a Mac, on code from this branch (`packages/web/public` served by `python3 -m http.server`), driven with Chrome (headless, via playwright-core installed in a temp directory outside the repo) at 1600x1000, and 390x780 at 3x for the phone.

**This replaces the first version of this PR.** That version put HTML cards over the page, in front of an iframe. The brief was for the content to be the billboard. Now the page is the billboard, with no iframe: one canvas, and the content is painted on the sign's face.

**Bottom line:** every step of #524 that the page can do ran in a real browser and passed: the five frames step in order, on the sign itself; the copy button copies the commands; the GitHub link opens the repo in a new tab; the `/bots` link goes to the page that does not exist yet; the bush, rock and tree were clicked; the tracker and localStorage followed. This change writes nothing to GitHub, so nothing was opened in `craftmilldev/loopway-sandbox`. **PostHog was faked:** `array.js` was replaced by a stub that records `posthog.capture` calls, so no test events reached Craftmill's real PostHog. The events below are what the page calls `capture` with, not what PostHog received.
