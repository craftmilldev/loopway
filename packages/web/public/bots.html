loopway

Bot files

loopway reads the .loopway/ folder in the directory it runs from. Each bot is one file, .loopway/<bot>.md: Markdown with YAML front matter. The front matter is the bot's rules; the Markdown below it is its prompt, which starts each thread's session. The file's name is the bot's name.

Front matter

repos
The repos the bot reads, as owner/name. A bot only counts for the repos it lists, and loopway polls the union of every bot's repos.
on
Which new subjects start a thread for the bot: issue, pull_request, or a list of both. A new issue starts a thread for every bot with on: issue, and a new pull request for every bot with on: pull_request.
model
Passed to Claude Code as its model, like sonnet. Left out, Claude Code picks.
harness
What runs the bot's sessions. Only claude (Claude Code), which is the default.
allow and deny
Lists of tool patterns in Claude Code's syntax, like allow: ["Bash(npm test:*)", "Read"]. They decide what the bot may do without asking you: deny is checked first, then allow, and anything else is asked on the thread for a 👍 or 👎.
max_bot_turns
The loop guard: how many comments from the bot user a thread takes in a row, with none from a person between. After that they are recorded but start no run, until a person comments. A whole number, 3 if left out.

Keys loopway does not know are ignored.

The prompt

Everything after the front matter is the prompt. It is the first thing each new session reads, followed by the thread's updates. Write it as you would brief a person: what the bot is, what it does, when to ask.

Examples

.loopway/dev.md takes issues and opens pull requests:

---
repos: [craftmilldev/loopway]
on: issue
---

You are the dev bot. When an issue is assigned to you, read it, make the change on a branch, run the tests, and open
a pull request that says `Closes #N`. Ask on the issue when something is unclear.

.loopway/review.md reads pull requests and reviews them:

---
repos: [craftmilldev/loopway]
on: pull_request
---

You are the review bot. Read the pull request and its diff, check it against the issue it closes, and leave a
review. Be specific, and say what you ran.
