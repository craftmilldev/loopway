Getting started · the whole idea

Services send webhooks. loopway hands them to a bot on your machine.

A bot is a coding agent, Claude Code or Codex say, running where your code and credentials already are. loopway keeps an inbox in front of it, and a runner on your machine picks each message up. Three steps, and the first is three commands.

GitHub, Linear, Vercel… sends a webhook
loopway inbox keeps the message
runner on your machine step 1 · this page
your coding agent does the work

Step 1 of 3 · on the machine where your code lives

Start a runner

Three commands. The last one stays open: it is the runner, and it waits for messages.

  1. 1 · Install Puts the loopway command on this machine. Needs Node 22 or newer.
    $ curl -fsSL https://loopway.craftmill.dev/install.sh | sh
  2. 2 · Log in Emails you a one-time code. Paste it back in the terminal.
    $ loopway login
  3. 3 · Run Starts the runner. Run it inside the repo your bots should work in, and leave it open.
    ~/code/your-repo $ loopway bots run --org mcwhittemore

You're in your personal org

mcwhittemore is yours alone and has no members, which makes it the simplest place to try things. To work with others, make a shared org first with loopway orgs create <slug>; bots and inboxes don't move between orgs.
